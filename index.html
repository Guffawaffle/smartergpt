Why lex-pr-runner

TypeScript-First Architecture

Modular TypeScript codebase with Zod schemas, Commander CLI, and comprehensive testing framework.

Schema Validation & Planning

Strict plan.json validation with cycle detection, unknown dependency errors, and deterministic output.

Dependency Resolution

Kahn's algorithm for topological sorting, deterministic merge order computation with conflict detection.

Local Gate Execution

Run lint, typecheck, and unit tests locally with timeout handling and structured output capture.

MCP Server Adapter

Model Context Protocol tools for plan.create, gates.run, and merge.apply with resource access.

Clean merges

Fast‑forward where possible, squash when it’s right, always predictable.

How it works

1) Configure & Validate

Set up .smartergpt/stack.yml with dependencies. Validate schema and detect cycles with comprehensive error reporting.

2) Compute & Order

Generate plan.json with deterministic merge ordering using topological sort and dependency resolution.

3) Execute & Verify

Run local gates (lint, typecheck, test), capture results, and prepare for clean integration merges.

Spin up the runner, compute the pyramid, and go.
