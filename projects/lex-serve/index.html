Origin TLS Setup

1) Generate Origin Certificate

Create a Cloudflare Origin Certificate in the SSL/TLS → Origin Server section. Download both the certificate and private key.

2) Install Certificates

Place certificates in /etc/ssl/cloudflare/ with proper permissions (600). Configure Nginx to use the origin certificate for HTTPS.

3) Configure Strict Mode

Set Cloudflare SSL/TLS encryption mode to "Full (strict)" to enforce end-to-end encryption and origin certificate validation.

Operational Runbook

Service Restart

# Restart the service
sudo systemctl restart lex-serve

# Check service status
sudo systemctl status lex-serve

# Verify health endpoint
curl https://serve.smartergpt.dev/health

View Logs

# Follow live logs
sudo journalctl -u lex-serve -f

# View recent logs (last 100 lines)
sudo journalctl -u lex-serve -n 100

# Filter by time range
sudo journalctl -u lex-serve --since "1 hour ago"

Check Worker Status

# List running workers
ps aux | grep uvicorn

# Check Redis connection
redis-cli ping

# Monitor job queue
redis-cli llen lex-serve:jobs
