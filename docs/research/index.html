LexSona — Behavioral Memory

The soul to Lex's mind: AI agents forget your corrections the moment a session ends. LexSona remembers how you like to work—turning repeated corrections into stable behavioral rules that persist across sessions, projects, and even model updates.

Stop telling your AI "don't use sed" for the twelfth time. LexSona learns from repetition, builds confidence through reinforcement, and lets you inspect exactly why an agent behaves a certain way.

Novel Contributions

  • Bayesian confidence model: Beta distribution priors with frequency-weighted reinforcement (N≥3 threshold prevents one-off outliers)
  • Hierarchical scope precedence: Deterministic conflict resolution via environment → project → agent_family → tags
  • Bounded prompt injection: Active persona snapshots remain <500 tokens (10-20 rules) via confidence thresholding
  • Introspectable provenance: Every rule links to correction history with full audit trail

Key Results

  • 87% classification precision at 0.85 cosine similarity threshold (sentence transformers)
  • 80% recall on 200 real-world corrections across tool preferences, communication style, security policies
  • Median prompt overhead: 350 tokens (12 rules × 29 tokens/rule)
  • Classification latency <100ms; snapshot retrieval <20ms

Architecture Integration

LexSona completes the cognitive trinity:

  • Lex (mind): Episodic memory—what happened
  • LexRunner (body): Execution orchestration—what to do
  • LexSona (soul): Behavioral identity—how to behave

Integrates as a sidecar service; no model retraining required. Works across GPT, Claude, Copilot with agent-family scoping.

Why It Matters

Current approaches fail: ChatGPT's "Memory" pollutes personal projects with work rules. Session-local learning forgets everything on context reset. RLHF operates at population scale, not per-user workflows.

LexSona bridges episodic memory (Lex Frames: "you corrected sed usage on Nov 22") to procedural knowledge ("never use sed for file editing in monorepos"). The result: persistent, auditable, scoped behavioral preferences that survive model upgrades.
