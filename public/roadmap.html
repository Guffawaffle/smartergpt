Current Status

✓ Lex 1.0.0 — Stable Contracts, Open Source

Lex 1.0.0 is available on npm (@smartergpt/lex) as the contract-bearing mind of SmarterGPT's agent infrastructure. The core contracts are stable enough to build on.

  • Frames — episodic memory with typed receipts and deterministic recall
  • lexmap.policy.json — module boundaries and architectural contracts
  • lex.yaml — intent-level workflow contracts for agent coordination
  • CLI commands: remember, recall, check
  • Typed TypeScript API with Zod-validated schemas
  • MIT license, Node ≥20, actively used in internal tooling

Roadmap

This roadmap tracks only the Lex open-source repository. It focuses on core engine stability, documentation, and integration ergonomics. Dates are indicative and may shift as we learn from real usage.
