Receipts turn agent work into evidence.

A receipt is a durable record that another agent, human, gate, or audit process can inspect later.

Receipt types

Memory receipt

A Lex Frame records what happened, what is blocked, what module was involved, and what should happen next.

Capability receipt

An AXF run records which capability executed, with what inputs, and what result or failure came back.

Authority receipt

An authority decision record captures the effect request, envelope, decision, and escalation reason if blocked.

Gate receipt

A LexRunner gate records the check, status, artifact, and whether the plan can advance.

Working rule

If an agent says it did something important, there should be a receipt somewhere: a Frame, command result, authority decision, gate result, or explicit denial.
