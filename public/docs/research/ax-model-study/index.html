AX Model Comparison Study

A rigorous, open scientific study comparing how different AI models comprehend and operationalize the Agent eXperience (AX) framework.

Active — Open Enrollment

Research Questions

  • Comprehension Fidelity Do models accurately extract the core AX thesis (legibility for non-human operators)?
  • Actionability Do models produce concrete, implementable next actions aligned with AX principles?
  • Self-Identification Can models reliably report their own identity when asked?
  • Cross-Model Variance How do responses differ across model families (Claude, GPT, Gemini, open-weight)?

How to Participate

  1. Download PROMPT.md and CONTROL.md
  2. Start a new, clean session with any model (no prior context)
  3. Copy the prompt exactly, inserting the control document where indicated
  4. Capture the complete response (do not truncate)
  5. Validate against RESPONSE-SCHEMA.json: npx ajv validate -s RESPONSE-SCHEMA.json -d response.json
  6. Submit your response via GitHub Issue or email
