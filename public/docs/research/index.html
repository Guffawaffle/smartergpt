The Cognitive Trinity

These research artifacts formalize three complementary layers of AI agent architecture:

🧠 Lex (Mind)

Episodic memory + policy indexing. Atlas Frames with adjacency-constrained recall. Remember what happened with architectural precision.

🔀 LexRunner (Body)

Deterministic orchestration. Merge pyramid with dependency-aware ordering, uniform gates, and predictable outcomes. A private layer built on Lex.

💭 LexSona (Soul)

Behavioral memory. Learn user preferences through Bayesian reinforcement. Persistent identity that survives sessions and model upgrades.
