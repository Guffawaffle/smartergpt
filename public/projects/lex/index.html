Lex: Policy-Aware Work Continuity

Lex is the open-source memory + policy engine in the smartergpt stack. It combines architecture policy-as-code with episodic memory (Frames) and Atlas Frames so you can ask "why is this blocked?" and get receipts from timestamped sessions, not vibes.

npm install @smartergpt/lex View on GitHub Read the overview

What is Lex?

🧠 Frames

Timestamped work session snapshots with summary, blockers, next action, and module_scope.

Local SQLite. No telemetry. MCP stdio.

🗺️ Atlas Frames

Fold-radius neighborhoods (default 1) around touched modules to keep context precise and small.

🔒 Policy

Machine-readable boundaries in lexmap.policy.json: ownership, allowed/forbidden edges, flags, permissions.

What's in v0.4.6-alpha

📦 MCP Server

Model Context Protocol server with stdio transport. Memory tools (lex.remember, lex.recall, lex.list_frames) and policy scanning integrated.

🔧 CLI Tools

Command-line interface with init, remember, recall, check, and more. JSON output mode for automation. Prompts management included.

🗄️ SQLite Storage

Local-first persistence with better-sqlite3. No cloud dependencies, no telemetry. Full control over your data.

📸 Image Support

Attach images to Frames (base64-encoded with MIME type). Uses Sharp for image processing.

🎯 Module Exports

Structured exports for cli, logger, prompts, memory/*, policy/*, and shared/*. Use as library or standalone CLI.

📋 JSON Schemas

Included schemas: profile.schema.json, feature-spec-v0.json, cli-output.v1.schema.json for validation and tooling integration.

Why it works

Shared Vocabulary = Receipts

Frames use the same module IDs as policy. Assistants and tools can cite policy violations from the exact time you left the work. That's explainable recall with receipts, not guesses.

Install

Lex v0.4.6-alpha is now on npm! Install globally for CLI access or as a dependency for programmatic use.

# Global install (CLI) npm install -g @smartergpt/lex@alpha # Or as a project dependency npm install @smartergpt/lex@alpha

After installation, run npx lex init to set up your workspace, then use lex remember, lex recall, lex check, and more.

See the GitHub repo for full documentation and examples.
